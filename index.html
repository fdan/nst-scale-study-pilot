Texture scale ordering

You'll see twelve sets of eight images. Each set is the same picture rendered at eight different texture scales.

Drag the images into order, from the finest texture first to the coarsest last. You'll see a worked example before you start. Click any image to see it larger, and use the size control if the differences are hard to make out.

If a set doesn't seem to have a single sensible order, put it in your best guess and tick the box below the strip. That's a useful answer, not a failure — it's the thing this pilot is looking for.

About fifteen minutes. Nothing is uploaded; you'll get a file at the end to send back.
