Artistic texture coarseness ordering

This pilot study helps determine if small changes in artistic texture coarseness are noticeable.

This must be done on a desktop computer, as the image size is a factor. If you are unable to complete it under ideal conditions, please do not continue as it can contaminate the results.

You'll see five sets of eight images. Each set is the same picture rendered at eight different texture scales. Your task is to order them from smallest to largest texture coarseness.

Visually this is analogous to zooming in on a painting — brush strokes and canvas substrate become larger.

Drag the images into order, from the finest texture first to the coarsest last. If you can't tell, go with your best guess — it's still useful statistically.

Once completed, you are given a file to download — please email that back to me.

Estimated time: 5 minutes. Nothing is uploaded; you'll get a file at the end to send back.
